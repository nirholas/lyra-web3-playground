# lyra-web3-playground examples

Lyra Web3 Playground - Learn blockchain development with interactive examples. Compile and deploy Solidity in your browser. Built by nich.

## Example 1

```bash
# Clone the repository
git clone https://github.com/nirholas/lyra-web3-playground.git
cd lyra-web3-playground

# Install dependencies
npm install

# Start development server
npm run dev
```

## Example 2

```bash
cp .env.example .env
```

## Example 3

```bash
npm run build
npm run preview
```
