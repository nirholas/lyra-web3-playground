# Getting started with lyra-web3-playground

Lyra Web3 Playground - Learn blockchain development with interactive examples. Compile and deploy Solidity in your browser. Built by nich.

## Install

```bash
npm install
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/lyra-web3-playground.git
cd lyra-web3-playground
```

Available commands:

| Command | Runs |
|---|---|
| `npm run dev` | `vite` |
| `npm run build` | `tsc && vite build` |
| `npm run lint` | `eslint . --max-warnings 20` |
| `npm run test` | `vitest` |
